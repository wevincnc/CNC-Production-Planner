Security

Data and backup

Everything is stored encrypted inside this browser on this device only; nothing is sent anywhere. An encrypted backup is a file that only opens with the user IDs and passwords that existed when it was made.

Users

Operator: enters jobs and sees only their own entries (can fix their own entries on the same day). Supervisor: sees and edits all entries, summary, CSV export, lists. Administrator: everything, including users, backup and import.
